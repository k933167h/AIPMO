AIPMO Runbook v1.3

설치

.env.example을 .env로 복사하고 PMO_API_KEY와 POSTGRES_PASSWORD를 변경합니다. docker compose up --build를 실행합니다.

반입/반출

X-API-Key 헤더를 이용하여 POST /api/v1/ganttax/imports에 JSON을 제출합니다. GET /api/v1/ganttax/imports/{import_id}/export에서 원본을 조회합니다.

자동 검증

python -m pytest -q. CI는 임시 PostgreSQL 서비스를 사용해 저장·재조회 통합 테스트를 수행합니다.

장애 대응

DB 연결 오류 시 DATABASE_URL 및 PostgreSQL healthcheck를 확인합니다. 401은 API 키, 422는 데이터 구조 및 필드를 확인합니다.

감사 증빙

GitHub Actions 로그, import ID, SHA-256, STAGED 상태를 확인합니다. STAGED는 승인된 기준선이 아닙니다.
