AIPMO Runbook v1.2

설치

.env.example을 .env로 복사하고 PMO_API_KEY, POSTGRES_PASSWORD를 변경합니다. docker compose up --build 실행 후 /docs를 엽니다.

반입

X-API-Key 헤더로 POST /api/v1/ganttax/imports에 GANTT-AX JSON을 제출합니다. 결과는 STAGED 상태로 저장됩니다.

반출

GET /api/v1/ganttax/imports/{import_id}/export로 원본 JSON을 가져옵니다.

테스트

python -m pytest -q

주의

원본 HTML 자체는 JSON이 아닙니다. 실제 프로젝트 상태 JSON을 별도로 내보내야 합니다. 데이터 반입은 기준선 승인이 아닙니다.
