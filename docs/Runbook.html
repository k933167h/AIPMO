AIPMO Runbook v1.1

설치

.env에 PMO_API_KEY를 설정한 후 docker compose up --build를 실행합니다. /docs에서 API를 확인합니다.

GANTT-AX 통합

원본 GANTT-AX v7.3은 참조용 단일 HTML입니다. 현재는 프로젝트 JSON 상태의 읽기 전용 정규화 코드만 구현했습니다. 실제 프로젝트 데이터의 서버 업로드와 동기화는 후속 단계입니다.

검증

pytest -q 실행. 잘못된 작업 ID, 선행 작업 참조 및 날짜 입력을 확인합니다.

승인과 감사

가져온 데이터는 승인된 Baseline이 아닙니다. 변경 적용 전 PM 승인을 요구합니다.
